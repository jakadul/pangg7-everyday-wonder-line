One sentence that makes a small everyday moment strange and new.

## What the entry is

A single sentence of at most 200 characters, held as a constant in `main.py`. The
judge weighs whether the angle is one the reader has not met, whether the surprise
lands in one read, and whether the image stays anchored in something real.

The sentence here is a kitchen kettle: the click, then one held second in the
room, with the house waiting all morning to be asked something.

## Run it

```sh
python3 main.py
```

No arguments, no network. The program checks the length against the gate, writes
the sentence to `/output/entry.txt`, and prints the code point count.
